## Critical Implementation Notes

**Content-Type Validation Approach:**
- Primary: Check `response.headers.get('Content-Type', '')` for JSON indicators
- Fallback: If headers missing or ambiguous, analyze response body (check for `<html>`, `{`, etc.)
- Non-JSON detection: Any response that is not valid JSON format should trigger validation

**Error Message Standards:**
Example formats that satisfy requirements:
- "Expected JSON response, got text/html (status 200)"
- "Expected JSON (application/json) but got text/plain"
- "Content-Type mismatch: expected application/json, received text/html"
