# Final Prompt: Web Scraper Bug Fix Implementation and Full Validation

## Role & Objective

You are a senior software engineer tasked with fixing a critical JSON parsing bug in a price monitoring web scraper project, creating a complete fixed project structure with proper documentation, and executing a comprehensive validation to ensure the fix works correctly across all scenarios.

## Input & Context

**Project Details:**
- Buggy project source: `issue_project/` (located in the workspace root)
- Target workspace: `<WORKSPACE>` directory (e.g., C:\BugBash\workSpace4)
- Fixed project destination: `<WORKSPACE>/issue_project_fixed/`
- Bug symptom: Parser crashes with `JSONDecodeError` when servers return HTML error pages or plain text instead of JSON
- Root cause: Response parser lacks content-type validation before attempting JSON parsing
- Current state: 5 of 14 tests failing

## Step-by-Step Instructions

### Phase 1: Bug Analysis and Fixed Project Creation

**Step 1.1: Analyze the Buggy Project**
- Examine `issue_project/src/parser.py` to identify where `json.loads()` is called
- Review test files to understand what behavior is expected
- Identify the specific method causing crashes when non-JSON responses occur
- Understand what exceptions the failing tests expect

**Step 1.2: Understand the Root Cause**
- Determine how response object structure works (headers, content-type, body)
- Identify what information is available to validate content-type
- Understand how to detect HTML and plain text responses
- Plan the minimal fix needed to resolve the issue

**Step 1.3: Create Fixed Project Directory Structure**
Create a new directory structure at `<WORKSPACE>/issue_project_fixed/` with this exact layout:
```

├── src/
│   ├── __init__.py         (copy unchanged)
│   ├── models.py           (copy unchanged)
│   ├── parser.py           (FIX THE BUG)
│   └── scraper.py          (copy unchanged)
├── tests/
│   ├── __init__.py         (copy unchanged)
│   ├── test_parser.py      (copy unchanged)

```

**Step 1.4: Copy Unmodified Files**
From original `issue_project/`, copy these files as-is:
- `src/__init__.py`
- `src/models.py`
- `src/scraper.py`
- `tests/__init__.py`
- `tests/test_parser.py`
- `tests/test_scraper.py`

**Step 1.5: Fix the Parser Bug**
Modify `src/parser.py` only:
- Add content-type validation before `json.loads()` call
- Check `response.headers['Content-Type']` for JSON indicators
- Implement fallback detection for HTML/plain-text when headers are missing
- Raise `ValueError` (not `JSONDecodeError`) for non-JSON responses
- Include helpful error messages mentioning both "json" and actual content-type
- Preserve `json.JSONDecodeError` for malformed JSON with proper content-type

- Check `response.headers.get('Content-Type', '')` for JSON indicators
